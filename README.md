# GRDC Conv

GRDC Conv is a free macOS application for downloading and converting online videos.

## Features

- Download videos
- Convert to MP4
- Convert to MP3
- Convert to WAV
- Video resolution selection
- Audio quality selection
- Custom download folder
- Download progress
- Download speed and estimated remaining time
- Cancel downloads
- Download history
- Automatic updates

## Requirements

- macOS
- Apple Silicon (M1 or newer)

## Installation

Download the latest version from the Releases section, extract the archive and move GRDC Conv.app to the Applications folder.

## Updates

GRDC Conv can check for new versions and download available updates.
